# Simple Calculator Web App

A simple and user-friendly calculator web application built using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations with interactive buttons and a clear display.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button to reset the calculation
- Interactive buttons and display
- Simple and responsive user interface
- Instant calculation results

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Calculator logic and functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/simple-calculator-web-app.git
```

### 2. Open the project folder

```bash
cd simple-calculator-web-app
```

### 3. Run the application

Open `index.html` in your web browser to start using the calculator.

No additional installations are required.

## 💻 Usage

1. Open the calculator in your browser.
2. Click the number buttons to enter values.
3. Select an arithmetic operator.
4. Enter the next number.
5. Press the equals (`=`) button to see the result.
6. Use the clear (`C`) button to reset the calculator.

## 🎯 Project Objective

The goal of this project is to practice fundamental web development concepts, including HTML structure, CSS styling, JavaScript event handling, and basic arithmetic operations.
